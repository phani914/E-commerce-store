# E-Commerce Store

A modern, responsive e-commerce website built with HTML, CSS, and JavaScript. The website is fully optimized for both desktop and mobile devices.

## Features

- **Responsive Design**: Optimized for all device sizes (mobile, tablet, desktop)
- **Modern UI**: Clean and professional design with smooth animations
- **Product Catalog**: Browse and view products with detailed information
- **Shopping Cart**: Add items to cart with persistent storage using localStorage
- **Newsletter**: Subscribe to newsletter for updates
- **Mobile Navigation**: Hamburger menu for mobile devices
- **Product Management**: Easy to add/manage products

## Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Responsive design with media queries, Flexbox, Grid
- **JavaScript**: DOM manipulation, localStorage API
- **Font Awesome**: Icons for UI elements

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/phani914/E-commerce-store.git
```

2. Navigate to the project directory:
```bash
cd E-commerce-store
```

3. Open `index.html` in your web browser:
```bash
open index.html
```

## Features Overview

### Homepage
- Hero section with call-to-action
- Featured products showcase
- Key benefits cards
- Newsletter subscription
- Professional footer

### Products Page
- Grid layout for products
- Product cards with descriptions and prices
- Add to cart functionality
- Responsive product grid

### Shopping Cart
- View all cart items
- Update quantities
- Remove items
- Order summary with total
- Persistent storage (cart data saved in localStorage)

### Responsive Design
- **Desktop**: Full navigation menu, multi-column layouts
- **Tablet**: 2-column feature cards, hamburger menu for navigation
- **Mobile**: Single column layouts, optimized touch targets, mobile-friendly navigation
